# AI-Based Customer Churn Prediction

## Project Overview

This project uses Artificial Intelligence and Machine Learning to predict customer churn.

The objective is to identify customers who are likely to leave a telecom service.

## Objective

The main objective is to build a Machine Learning model that predicts whether a customer will churn or not.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Machine Learning
- Logistic Regression
- Jupyter Notebook
- Power BI

## Machine Learning Workflow

1. Data Loading
2. Data Cleaning
3. Feature Selection
4. Data Preprocessing
5. Train-Test Split
6. Machine Learning Model Training
7. Churn Prediction
8. Model Evaluation
9. Power BI Dashboard

## Model Evaluation

The model is evaluated using:

- Accuracy
- Precision
- Recall
- ROC-AUC
- Confusion Matrix
- Classification Report

## Project Files

- `churn_prediction.ipynb` — Complete Machine Learning notebook
- `Churn_Dashboard.pbix` — Power BI dashboard

## Conclusion

This project demonstrates how Artificial Intelligence and Machine Learning can be used to predict customer churn and support data-driven customer retention decisions.
